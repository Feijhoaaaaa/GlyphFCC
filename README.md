﻿\# GlyphFCC



GPU-accelerated image processing and character-based visual effects, built with C++ and NVIDIA CUDA.



\## Overview



GlyphFCC is an experimental GPU computing project focused on transforming images into animated visual representations using characters.



\### Planned Features



\- Image loading and preprocessing

\- Grayscale conversion and contrast enhancement

\- GPU-accelerated brightness analysis

\- Character-based animation driven by image brightness

\- Unicode character rendering and color support

\- Video export



\## Technology Stack



\- \*\*Language:\*\* C++20

\- \*\*GPU Computing:\*\* NVIDIA CUDA

\- \*\*Build System:\*\* CMake

\- \*\*Compiler:\*\* Microsoft Visual C++ (MSVC)

\- \*\*IDE:\*\* Visual Studio Community



\## Requirements



\- Windows 10/11 (64-bit)

\- Visual Studio with C++ development tools

\- CMake

\- NVIDIA CUDA Toolkit

\- CUDA-compatible NVIDIA GPU



\## Build Instructions



Run the following commands from the repository root using a Visual Studio x64 developer environment:



```powershell

cmake -S GlyphFCC -B build/GlyphFCC -G "Visual Studio 18 2026" -A x64

cmake --build build/GlyphFCC --config Debug

```
